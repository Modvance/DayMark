# Daymark 0.5.1 · 今天的行动，长期的方向

面向个人的 Windows 本地日程应用。保持 0.4 的浅色/深色界面，连接「每天的任务」与「长期目标」。无需账号，数据保存在本机。

## 先看界面

解压后双击 `preview.html` 或 `widget-preview.html`，点击「载入示例」。示例中的考试日期只是演示，请自行填写真实日期。浏览器预览与正式桌面数据独立；预览不提供 Windows 桌面挂载、系统通知、托盘或全局快捷键。

## 安装版：直接安装使用

下载发布文件 `Daymark-Setup-0.5.1-x64.exe`，双击后按中文安装向导完成安装。从桌面或开始菜单的 Daymark 图标启动，无需 Node.js、脚本、命令行或另行下载运行环境。安装包面向 Windows 10/11 x64，默认安装在当前用户目录，也可以选择目录。

升级前建议先导出备份，再从旧版设置或托盘选择「完全退出」。使用同一个 Windows 用户安装新版，继续读取原来的本机数据；未来升级也直接安装新版即可，无需先卸载。

关闭主窗口会保留托盘及组件；完全退出请在托盘或设置选择「完全退出应用」。设置中的开机启动会登记当前安装的 Daymark.exe，设置也会读取 Windows 的实际启动项状态。设置底部显示版本号。

在 Windows 的「设置 → 应用」中可以卸载。卸载保留日程数据与备份，仅清理程序、快捷方式及本应用的开机启动项。重装可继续使用原数据。

本安装包未配置 Authenticode 代码签名，Windows 可能提示「未知发布者」或信誉确认。当前未接入自动更新服务，使用新安装包手动升级。安装、Win+D、系统通知及多屏仍需 Windows 实机验收，构建与静态包校验不代表已经完成实机测试。

应用名称和正式数据路径保持不变。数据格式为 version 2；首次保存旧格式数据前，会保留原文件为 `tasks.json.pre-v0.5.bak`，不随日常写入覆盖。旧版不能识别新格式，请勿直接用旧版程序打开升级后的正式数据。

## 推荐的第一次使用流程

1. 在左侧「长期目标」中新建一个目标，例如英语四六级或 CSP。
2. 填写真实截止日期、每周希望完成的关联任务数，再添加几个阶段。
3. 从阶段点击「加入今天」，或选择日期加入日程；也可以添加更具体的关联任务。
4. 在「今天」完成任务，目标自动留下推进记录；点「撤销」或重新打开任务，会撤回该任务的完成记录。
5. 在桌面组件同时查看今日待办与目标倒计时，不必来回切换标签。

## 今天与日程

- 只填标题即可快速记录任务。今天视图中回车新增会自动加入今天。
- 计划日期、开始时间、预计用时、截止时间分开设置；开始时间与预计用时均可选。
- 今天/选定日期支持清单与时间轴。对同一天明确填写开始时间和时长的未完成任务，提示时段重叠。
- 可以启用「计划开始时提醒」。只提醒当天计划，不在启动时补发过去日期的开始提醒。
- 「之前未完成」默认收起，支持移至今天、编辑重排、暂不安排；不会自动把历史任务全部塞到今天。
- 任务可关联一个长期目标，也可指定该目标中的阶段。
- 完成任务可撤销；标记重要、搜索、月历、分类与数据备份继续可用。

## 长期目标

目标包含名称、说明、截止日期、状态、每周目标、阶段里程碑与推进记录。

- 截止倒计时按本机日历日期计算。今天到期显示「今天到期」，过期后保留目标并显示到期天数，不自动结束。
- 状态可以是进行中、暂缓、已结束。
- 「每周目标」的单位为完成的关联任务数；0 表示不设置每周数量目标。
- 「阶段完成情况」来自你手动确认的里程碑，不根据时间流逝或勾选任务数计算考试准备百分比。
- 完成关联任务会记入推进记录。修改截止日期不清空历史。删除已完成任务会保留历史行动；撤销完成会移除该任务记录。
- 同一阶段在同一天的未完成任务不会重复创建。阶段任务默认不继承目标截止日期，避免将每个练习都变成同一个远期 deadline。
- 一段时间没有完成关联任务时，会显示停滞提示；没有动作记录时提示尚未开始。
- 删除目标会保留原日常任务，并解除任务和重复计划的目标关联。

## 重复计划

任务详情支持每天、周一至周五、每周同一天。

- 应用运行时生成当天的实例，不批量补生成关机期间的历史任务。重复任务在当天的开始时间之前就会进入今天清单。
- 删除一次任务只删除本次，不会当天反复重建；停止整个系列请在任务详情将重复设为「不重复」并保存。
- 在详情保存标题、目标、时段、用时等，会用于之后的实例；普通完成、标记或移动历史任务不会覆盖系列模板。
- 移动某次日期只移动这一次；改变重复规则会用本次计划日期作为新周期起点。
- 后续实例继承开始时段、用时等，不复制某一天的单次截止日期。
- 暂缓或结束目标后，暂停生成它的关联重复任务；已有日常任务仍然保留。恢复目标时仅生成符合规则的当天实例。

## 桌面组件

- 上方为今日待办，下方持续显示最多 3 个已固定的进行中目标，按截止日期排序。两个区域分别滚动，目标倒计时不会随任务一起滚走。
- 底部可以选择新任务关联哪个目标，再快速添加今日任务。
- 点目标进入主窗口的目标详情。折叠时显示今日剩余项数和最近目标的倒计时。
- 最小尺寸下收起「显示已完成」入口，以给今日任务和目标倒计时留出空间；完整完成清单可在主窗口查看。
- 保留桌面/置顶切换、四边缩放、默认尺寸、不透明度、位置记忆和找回组件。

Windows 桌面层由原生辅助代码挂载。挂载失败会提示并恢复为置顶。原生 Win+D 行为、通知和多显示器 DPI 仍需 Windows 实机验收。

## 提醒规则

- 计划开始提醒：按计划日期和开始时段检查，当天恢复运行可补发一次。
- 单项任务截止提醒：截止时或提前 15 分钟/1 小时/1 天，一次提醒。
- 长期目标节点提醒：默认提前 30/14/7/3/1 天及截止当天；可自定义节点或关闭。重启跨过多个节点时合并补发并去重，不逐个刷屏。
- 所有提醒需要应用运行，检查间隔约 15 秒。完全退出、关机、休眠期间不能及时通知；系统通知受 Windows 权限和勿扰设置影响。
- 暂缓/已结束目标不发送目标节点提醒。日常任务仍按自身设置处理。

## 数据与备份

正式数据在 Electron `userData` 目录中的 `tasks.json`，沿用旧版位置。日常写入还保留上一次的 `tasks.json.bak`。主文件损坏时会停止启动并显示位置，避免覆盖原数据。

设置中可导出/导入完整 JSON，包含任务、目标、阶段、推进记录、重复计划。导入补充新编号条目，同编号保留本机内容；不会覆盖本机已有目标及其记录。迁移、导入和无效输入均有自动化测试。

## 快捷键与构建

- Ctrl+N：在目标页新建目标，其他页面新建任务。
- Ctrl+K / Ctrl+F：搜索当前任务或目标。
- Ctrl+,：设置。
- Ctrl+Shift+Space：全局唤起并新建任务。

```powershell
npm.cmd test
npm.cmd run preview
npm.cmd run dist:win
```

安装包在 `dist/`。Windows 可运行 `npm.cmd run release:win`，依次执行测试、生成预览、构建 NSIS 安装包和包内容校验，并生成 `SHA256SUMS.txt`。

Linux 交叉构建未签名版本：

```bash
npm ci
npm test
npm run preview
npm run dist:win:linux
npm run verify:release
```

交叉构建脚本使用固定版本 electron-builder 的标准 NSIS 模板及原有卸载程序提取器，不运行 Windows 代码。PE 资源编辑保留 Electron 的 manifest 与 asar integrity；最终校验实际安装包和打包文件。发布代码签名需要开发者自己的证书，请在 Windows 配置后使用原生 `dist:win` 构建。

## 代码

- `src/domain.js`：共享数据模型、迁移、目标统计、重复计划、提醒与状态变更。
- `src/model.cjs`：磁盘存储、原始数据保护和备份。
- `src/ui.js`：共享图标、视图过滤、时间轴与预览桥接。
- `src/goals.js`：目标列表、详情、阶段编辑与安排到日程。
- `src/renderer.js` / `panel.js`：主窗口与桌面组件交互。
- `src/main.cjs` / `preload.cjs`：原生窗口、同步、通知及全局快捷键。
- `src/native/`：Windows 桌面挂载与原生圆角。
- `test/`：数据模型、完整界面流程与模拟窗口联动测试。
